# Attractors

Visualization of some attractors of dynamical systems in Typescript and WebGL.
A live version can be found [here](https://relint.de/attractors.html).

## Development

1. Install [`pnpm`](https://pnpm.io/).
2. Run the following:
   ```bash
   pnpm intall
   pnpm run dev
   ```
